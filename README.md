💻 Soy un joven Ingeniero Agrónomo con interés en el desarrollo de soluciones basadas en datos para la agricultura.
- 🌱 **Dominio Técnico:** Python (Pandas, Numpy, Scipy, Scikit-Learn, XGBoost), SQL y Power BI aplicado al Agro.
- 🍌 **Banano:** Implementación de Modelos de Riesgo Fitopatológico y Auditoría Digital de Bioseguridad para prevención de Fusarium R4T.
- 🌾 **Arroz:** Modelado de Rendimiento mediante Regresión Lineal y Polinomial. Pronóstico de cosecha basado en variables climáticas y manejo hídrico.
- 🌽 **Maíz:** Validación de Ensayos de Rendimiento mediante ANOVA y Prueba T. Optimización de densidades de siembra y eficiencia de fertilización nitrogenada.
- 🍫 **Cacao:** Monitoreo de Salud Radicular y Nutrición Foliar. Análisis microbiológico para el control de enfermedades y optimización de enmiendas orgánicas.
